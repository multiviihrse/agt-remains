# AGT: Remains

Portal do RPG **AGT: Remains**, ambientado em Rosehound Falls, Minnesota.

## Publicação

O site é estático e pode ser publicado gratuitamente no GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Organização

- `index.html`: estrutura e textos das páginas.
- `styles.css`: identidade visual, layouts e responsividade.
- `script.js`: navegação e interações.
- `config.js`: links opcionais para os Google Forms.
- `.nojekyll`: impede processamento Jekyll desnecessário.

## Importante

Não inclua planilhas com respostas privadas, tokens, senhas nem informações pessoais no repositório público. As URLs de banners são externas e dependem da disponibilidade dos serviços de imagem.

A versão publicada preserva as seções e a estrutura de cartões + resumo da trama, mas os ornamentos rasterizados dos protótipos locais (lettering, lua, decoração da sidebar) deverão ser incorporados como arquivos de imagem em uma atualização posterior para identidade visual idêntica.
